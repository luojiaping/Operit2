# 2.0.0-preview.23 · 本地开发版更新日志

对比基线：Build 28 / 2.0.0-preview.22，提交 `db9b7dc5e14caf5fcc4c74593b79f90294050d66`。
本次内容：提交 `db9b7dc5` 之后至 `4b3a2299` 的本地变更，尚未发布构建。
以下内容面向用户端，按用户可感知的功能组织；不含 CI、测试维护及纯内部重构。

## 全平台

### 聊天与发送

• 新增“引导当前对话”：AI 正在回复时，长按发送可三选一——排队（默认）、不打断地引导当前任务、打断并立即发送。引导不打断进行中的模型请求和工具调用，会在下一次模型请求时生效；排队消息也新增“引导当前对话”与“撤回到编辑框”操作。
• 聊天附件改为持久保存：普通文件、粘贴图片重启后仍可读取，不再随启动清理删除；旧消息中已被清理的临时附件会明确提示重新上传。附件目录不参与多设备同步，需要共享的文件仍应复制进工作区。
• 上下文压缩提示词重写为“交接检查点”：总结不再千篇一律，聊天会话按话题与语气总结，代码会话按工程交接总结（文件、命令、错误、下一步）；逐条保留用户消息要点与安全约束，并校验输出格式，不合格时自动重试一次。压缩阈值从 70% 提高到 85%，减少过早压缩。
• AI 生成的交互式界面（OpenUI 程序）现在作为独立消息部件保存与展示，不再被当作 LaTeX 公式渲染成一团乱码。

### 工作区

• 每轮编辑快照与回滚：AI 修改文件时自动保留该轮快照，消息下方显示本轮改动汇总（文件数、增删行数），可一键审查统一 diff 或撤销整轮改动。仅保留最近一轮快照，更早的改动请使用 Git。
• `write_file` 工具现返回统一 diff，AI 与用户都能直接看到每次写入改了什么。
• 新增会话内 diff 视图：顶栏一键查看本轮全部文件变更，支持逐文件切换、并排/内联两种模式、行内差异高亮。
• 侧栏重做：会话可按项目分组并置顶；新增项目绑定、移动到项目操作；顶栏改为“工作区名 - 会话标题”两级显示。
• `chat new` 命令支持 `--workspace` 参数，创建会话时直接绑定工作区。

### 外观

• 消息样式拆分：用户消息与 AI 消息可分别选择命令行/气泡样式，外观设置中出现两个独立选项。
• 工具调用展示统一重做：紧凑行内摘要 + 点击展开详情，文件改动直接内嵌 diff 视图，思考过程与工具结果分组更清晰。
• 附件查看器全新设计：图片全屏毛玻璃查看，支持双击缩放、双指缩放与拖动；其他类型以居中卡片预览。
• 插件界面（Compose DSL）新增 SegmentedControl、Select 下拉和 Table 表格组件。
• 流式 Markdown 新增行内 LaTeX 解析，公式在输出过程中即可正确渲染。

### 其他

• 新增剪贴板工具：AI 可直接写入系统剪贴板（`set_clipboard_text`），插件侧同步暴露 `System.setClipboardText`。
• 浏览器会话改为异步等待，AI 操作浏览器时不再阻塞其他任务；网页访问（web visit）在应用内以嵌入式 WebView 呈现，无需跳转外部浏览器。
• 文件传输改走 Host 通道：大文件分块读写、断点续传不再依赖本地 `std::fs`，Android、iOS、Web 等平台行为一致。
• 数据救援边界修复：Android `/data/user/0`、Apple `/var` 等系统路径别名先解析为物理路径再进入原生层，避免备份/恢复因符号链接被拒。
• 移除内置 thinking_guidance 插件包；相关功能由新的引导机制取代。

## 桌面端（CLI / TUI）

• 新增 `/diff` 命令：查看当前会话记录的全部文件变更，支持 j/k 滚动、`[`/`]` 切换文件、Tab 切换并排/内联、`e` 用外部编辑器打开。
• 聊天记录中的 diff 代码块现在带语法着色（增绿删红、变更行高亮）。
• 回滚提示更明确：快照已被覆盖时会说明只保留最近一轮，建议使用 Git。

## 已知限制

• 引导当前对话仅支持纯文本，带附件或回复目标时会提示先移除。
• 每会话仅保留最近一轮工作区快照，更早的改动无法通过应用内回滚恢复。
