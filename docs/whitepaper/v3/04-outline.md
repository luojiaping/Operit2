## 1. 题目与主论点

**题目：** Operit2 技术白皮书 3.0——个人设备空间中 LLM Agent 的回合边界续跑：执行所有权的形式化分析与代次隔离协议

**主论点：** 在回合边界上，LLM Agent 的控制状态完全外化为持久事实，因此跨设备续跑可以从“进程迁移问题”降为“执行所有权转移问题”。但在没有中心协调者、副本最终一致的个人设备空间中：
- 所有权转移需要代次隔离，才能满足单一推进与续跑至多一次；
- 不能同时保证 owner 不可达时的接管与执行互斥，取舍必须显式地交给用户；
- 数据交接完整，不保证模型对环境的信念仍然成立。
