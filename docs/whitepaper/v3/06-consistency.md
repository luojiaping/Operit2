## 1. 自动检查

`build_v3.py` 在每次构建时检查以下各项，任一项出错即以非零状态退出：

| 检查项 | 规则 | 结果 |
| --- | --- | --- |
| 文献键 | 正文中每个 `[@Key]` 都在 `references.json` 中定义 | 通过 |
| 未引用文献 | `references.json` 中的每条都被正文引用（违反时警告） | 46 条全部被引用 |
| 证据编号 | 正文中的每个 `[Cn]` 都在附录 A 中定义，附录 A 的每个编号都被正文使用（违反时警告） | 通过 |
| 图 | 每个 `![…](…)` 指向的 SVG 文件都存在 | 4 张图都存在 |
| 表格 | 同一表格各行的列数相同（渲染器的要求） | 通过 |
| 占位符 | 正文中不得残留 `TAKEOVER_SAFE_RESULT`、`EXPERIMENT_ROWS` | 通过（结果填入后） |

参考文献按首次出现的顺序编号，由构建脚本统一生成，正文中没有手写编号。
