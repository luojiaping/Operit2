## 3. 与阶段一决定的差异

阶段一 D2 建议 3.0“取代 2.0”。定稿时，3.0 采用补充 2.0 的写法：扩展、平台、本地推理与记忆插件的描述仍以 2.0 为准。根目录 README 把白皮书描述为“项目初衷、工程架构与长期方向”，并标注“中文版 2.0”，这一描述与 3.0 的内容不符。

因此，3.0 发布为 `docs/Operit2技术白皮书-3.0.pdf`；`docs/Operit2技术白皮书.pdf` 保持为 2.0，与 git index 中已暂存的版本逐字节一致。`docs/README.md` 的白皮书一节已同时列出两版。根目录 README 没有修改。
